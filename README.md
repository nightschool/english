# English Study · 英语精读

用英文报刊原文精读**词汇**与**长难句**，面向中文母语者。
每篇讲义都是一个独立的 HTML 页面，包含核心词汇卡片（含原文例句与搭配）、
长难句的意群拆解与语法分析、地道表达表、自测题，以及可导入 Anki 的生词表。

**📖 在线阅读：https://nightschool.github.io/english/**

> 手机上直接打开上面的链接即可，页面自带浅色/深色主题、中文遮盖自测、
> 生词掌握进度（存在浏览器本地），无需登录、无需网络请求。

## 页面功能

| 控件 | 作用 |
|---|---|
| **🔊** | 朗读单词、例句与长难句；再点一次停止。超过 200 字符的句子会自动分段连续播放 |
| **语速 1× / 0.7×** | 放慢朗读速度且不变调，适合跟读长句 |
| **中文：显示 / 已遮盖** | 遮盖全部中文释义与译文用于自测；单击某一块可只揭开这一块 |
| **已掌握** | 勾选后计入顶部进度条，记录在浏览器本地，重新生成同一课不会丢失 |
| **主题** | 系统 → 深色 → 浅色循环，所有课程共享 |
| **打印** | 展开全部答案与仿写参考，卡片不跨页断开 |
| **复制生词表** | 制表符分隔，可直接粘贴进 Anki（正面 / 背面 / 例句） |
